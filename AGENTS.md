# Reignite — Project Rules

## Readiness score architecture
- The official readiness score is AI-generated by `supabase/functions/generate-report` and lives in `ai_reports`. The Plan Editor shows a client-side live estimate from `src/lib/readiness.ts` (presentation-only, same assumptions: 8% return, 4% safe-withdrawal rule) — never replace the official score with the estimate.
- "Save & update my score" calls `generate-report` with `regeneratePlan: true` (skips re-seeding business ideas to avoid duplicates) and `planData` inputs so plan edits move the official score. Any new plan input must be passed through `planData` and surfaced in the prompt's plan block.

## Dashboard data flow
- Dashboard state comes from `src/hooks/useDashboardData.ts` (React Query + realtime). New tab features should consume its state/props rather than adding parallel queries unless self-contained (e.g. `GoalsSection`).
